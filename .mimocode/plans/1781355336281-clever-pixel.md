# Xray Dashboard — Comprehensive Issues & Improvements Plan

## Phase 1: Critical Security Fixes

### 1.1 Remove credential exposure from `/api/config` endpoint
**File:** `xray-proxy-server.js:172-184`

The `/api/config` endpoint returns `jiraApiToken`, `xrayClientId`, and `xrayClientSecret` in plain JSON. Any client can hit this URL and get full credentials.

**Fix:** Remove the `/api/config` route entirely. The dashboard should use its own `env.js` for browser-mode credentials, and server-mode should proxy requests using server-side credentials (which it already does for `/api/jira/search` and `/api/xray/graphql`).

### 1.2 Switch localStorage to sessionStorage
**File:** `xray-test-dashboard-v17.html:3321,3325`

`saveFullConfig()` stores API tokens, bearer tokens, and client secrets in `localStorage` which persists across browser sessions. `sessionStorage` clears when the tab/browser closes and limits exposure.

**Fix:** Replace `localStorage` with `sessionStorage` in `saveFullConfig()` and `loadFullConfig()` (lines 3321, 3325).

### 1.3 Add request body size limit
**File:** `xray-proxy-server.js:68-75`

`readBody()` accumulates all chunks without any size limit. A malicious POST can consume unbounded memory.

**Fix:** Track accumulated size and destroy the request if it exceeds a reasonable limit (e.g. 1MB).

## Phase 3: Code Quality Improvements

### 3.1 Apply escapeHtml consistently in RuntimeEnv._updateUI
**File:** `xray-test-dashboard-v17.html:2974,2978`

`this.serverInfo?.server?.platform` and `nodeVersion` are injected via template literals without `escapeHtml()`. While the data comes from the local `/health` endpoint, this is inconsistent with other innerHTML assignments.

**Fix:** Wrap values in `escapeHtml()`.

### 3.2 Add error logging to catch-all handler
**File:** `xray-proxy-server.js:223-225`

The catch handler returns `e.message` but never logs the stack trace, making debugging difficult.

**Fix:** Add `console.error('[' + reqId + ']', e.stack || e.message)` before returning the error response.

### 3.3 Remove old versioned dashboard files
**Files to delete:** `xray-test-dashboard-v14.html`, `xray-test-dashboard-v15.html`, `xray-test-dashboard-v16.html`

Only v17 should be kept. Old versions inflate the repo and create maintenance drift.

**Fix:** Delete v14, v15, v16 HTML files.
